# Echo-lite

Echo-lite is a tiny rule-based conversational agent written in Python.

## Features

- Responds to simple greetings.
- Answers basic questions.
- Provides a lightweight reply function.

## Requirements

Python 3.10 or newer.

## Usage

Run the example:

```bash
python echo_lite.py
```

Example:

```python
from echo_lite import reply

print(reply("hello"))
```

Output:

```text
Hello! How can I help you?
```
